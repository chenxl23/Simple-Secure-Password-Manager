# Simple Secure Password Manager (Pro) 🛡️

这是一个基于 Python 开发的极简、安全、本地优先的密码管理器。专为个人核心资产管理设计，支持各大平台账号的分类归集与高强度的本地物理隔离加密。

## ✨ 核心特性

- **macOS 浅色美学**：彻底重构 UI 引擎，采用苹果级的极简浅色调（Light Mode）。全局应用微软雅黑（Microsoft YaHei）与 Consolas 专属等宽字体，配合 2 像素锐利边框与定制圆角，视觉清透舒适。
- **自定义分类与安全闭环**：支持无限制创建个性化分类（如社交、金融、开发）。特有**孤儿数据迁移机制**，在删除某分类时，其名下账号会自动安全回流至「默认」分类，绝不丢失数据。
- **动态内存级安全**：深度介入 Python 垃圾回收机制（`gc.collect()`）。在每次解密查看、密码修改及锁定金库后，瞬间从底层内存中强制抹除密码明文残影。
- **剪贴板定时熔断**：新增 5 秒安全保护期。点击复制密码后，系统会在 5 秒后精准且智能地自动清空剪贴板，防止其他软件后台窃取。
- **零知识证明与高强度加密**：所有数据均使用 **AES-256 (Fernet)** 在本地对称加密。主密钥通过 **PBKDF2HMAC** (SHA256, 48 万次极高强度迭代) 实时派生，程序不留存任何明文主密码。
- **双保险灾备恢复**：提供“安全恢复码 (Recovery Key)”方案。首次初始化时不仅会弹窗提示，还会**自动在本地生成 `安全恢复码备份.txt`**。即使忘记主密码，通过该文件也能 100% 重置并找回所有数据。

## 🚀 快速开始 (Windows)

为了方便日常使用，我们在根目录下准备了快捷批处理脚本：

1. **第一步：安装依赖** 双击 `安装依赖.bat`。它会自动检测你的 Python 环境并快速安装 `cryptography` 和 `customtkinter` 两个核心库。
   
2. **第二步：运行程序** 双击 `快捷启动.bat`。即可瞬间拉起可视化的金库操作界面。

*如果你想在命令行手动运行：*
```bash
pip install cryptography customtkinter
python password_manager.py
```

## 📂 项目文件结构
- `password_manager.py`: 核心程序源码
- `my_passwords.json`: 加密后的本地数据库核心文件（**请务必定期通过 U 盘或云盘备份此文件**）
- `安全恢复码备份.txt`: 系统初始化的自动备份文件（包含重置密码的唯一凭证，**建议妥善保存后将其隐藏或移至安全位置**）
- `安装依赖.bat`: 环境配置脚本
- `快捷启动.bat`: 一键启动脚本

## ⚠️ 终极安全指南
1. **主密码是第一道防线**：日常解锁全靠它，请设置一个你绝对不会忘的密码。
2. **恢复码是最后一道底线**：当系统崩溃或主密码遗忘时，`安全恢复码备份.txt` 里的代码是解密 JSON 文件的**唯一数学手段**，若两者同时丢失，神仙难救。
3. **隔离策略**：虽然数据已被军事级加密，但仍建议不要在网吧等不受控的公共设备上留下你的 `my_passwords.json` 实体文件。
