# Simple Secure Password Manager (Pro) 🛡️

这是一个基于 Python 开发的极简、安全、本地优先的密码管理器。专为个人账号管理设计，支持微信、QQ、谷歌、Outlook 等各类账号。

## ✨ 核心特性

- **零知识证明架构**：所有数据均在本地使用主密码加密，任何云端或第三方都无法窥探。
- **高强度加密**：采用 **AES-256 (Fernet)** 对称加密，密钥通过 **PBKDF2HMAC** (SHA256, 48万次迭代) 从主密码派生。
- **现代 UI 界面**：基于 `ttkbootstrap` 构建，支持实时搜索、一键查看、修改和删除账号。
- **安全找回机制**：提供**安全恢复码 (Recovery Key)** 方案。即使忘记主密码，只要持有初始化时生成的恢复码，即可安全重置并找回数据。
- **字段级加密**：仅对敏感的密码字段进行加密，保留平台名称 and 账号名以便快速搜索。

## 🚀 快速开始

### 1. 安装依赖
确保你的电脑已安装 Python（推荐使用 Anaconda 环境），并在终端运行：
```bash
pip install cryptography ttkbootstrap
```

### 2. 运行程序
直接运行 `password_manager.py`：
```bash
python password_manager.py
```

## 📂 项目结构
- `password_manager.py`: 核心程序代码
- `my_passwords.json`: 加密后的本地数据库文件（由程序自动生成，**请务必妥善备份此文件**）

## ⚠️ 安全警告
1. **主密码是唯一凭证**：请务必记住你的主密码，程序不记录明文主密码。
2. **备份恢复码**：首次运行时生成的 `RM-` 开头的恢复码是忘记密码时的唯一救命稻草。
3. **本地安全**：虽然数据已加密，但仍建议不要在公共电脑上留下你的密码本文件。
